# Steelon Exchange Bot

Бот показує останню збережену таблицю EUR, може надіслати її в особисті
повідомлення або у Steelon, показує час останнього оновлення і дає змогу
користувачу ввімкнути чи вимкнути щоденну розсилку.

## Що з'явилося

Після `/start` у приватному чаті з ботом є кнопки:

- **Надіслати мені курс** — надсилає актуальну збережену таблицю;
- **Надіслати курс у Steelon** — публікує таблицю в задану групу/канал;
- **Останні оновлення** — показує таблицю та час її останнього оновлення;
- **Отримувати щодня** / **Вимкнути щоденні** — керує персональною розсилкою.

Кнопка публікації в Steelon доступна лише ID із `TELEGRAM_ADMIN_IDS`. Це не
дає будь-якому користувачу бота надсилати повідомлення від імені каналу.

## Запуск 24/7

Інтерактивні кнопки потребують постійно запущеного процесу: GitHub Actions не
може постійно чекати натискання кнопок Telegram. Найпростіший запуск — Docker
на сервері, VPS або хостингу, що підтримує Docker.

1. Створіть файл `.env` на основі `.env.example`.
2. У `BOT_TOKEN` вставте токен від @BotFather.
3. Додайте бота в групу/канал Steelon як адміністратора і вкажіть її ID або
   `@username` у `STEELON_CHAT_ID`.
4. Дізнайтеся свій числовий Telegram ID (наприклад, через @userinfobot) і
   вкажіть його в `TELEGRAM_ADMIN_IDS`.
5. Запустіть `docker compose up -d --build`.

Контейнер оновлює курс щогодини з 09:00 до 18:00 за Києвом. Після першого
оновлення кожного дня підписники отримують одну персональну таблицю.

Дані підписок і історія лежать у папці `data/`, тому вони не зникають після
перезапуску контейнера. Не запускайте одночасно цей контейнер і GitHub Actions
для публікації курсів — інакше в Steelon будуть дублікати. Після переходу на
контейнер вимкніть workflow **Daily currency rates to Telegram** у вкладці
Actions або залиште тільки ручний запуск.

## Локальний запуск без Docker

Створіть віртуальне середовище, встановіть залежності з `requirements.txt`,
заповніть змінні з `.env.example` у середовищі й виконайте:

```text
python telegram_bot.py --with-rate-updater
```

Для приймання повідомлень у BotFather має бути вимкнено webhook, якщо він був
налаштований раніше: режим у цьому проєкті використовує long polling.
